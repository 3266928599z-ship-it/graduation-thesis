# graduation-thesis

基于 CAD 先验模型与线激光扫描的免示教焊接机器人技术研究 —— 硕士学位论文开题答辩资料。

## 课题

- **题目**：基于 CAD 先验模型与线激光扫描的免示教焊接机器人技术研究
- **技术路线**：CAD 先验提取 → 线激光扫描（eye-in-hand）→ 焊缝位姿感知 → 工艺×运动学六自由度免示教轨迹规划 → 焊缝偏差自适应调整 → 系统集成与实验验证
