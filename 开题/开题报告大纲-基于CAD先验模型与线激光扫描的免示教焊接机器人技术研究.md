# 开题报告大纲（新题目对齐版）

**题目：基于 CAD 先验模型与线激光扫描的免示教焊接机器人技术研究**

> 说明：本文档为新题目下的开题报告大纲，用于对齐题目、技术路线、研究内容、关键问题与实验方案。目标场景为曲线焊缝，线激光相机安装于机械臂末端（eye-in-hand）。

---

## 一、选题背景与研究意义

### 1.1 选题背景

- 焊接自动化产业背景：钢结构、船舶、轨道交通、重型装备制造的基础工艺；焊工短缺、人工成本攀升。
- 工业机器人增长与自主适应能力不足的矛盾：机器人数量增长 ≠ 自主适应能力提升。
- 传统示教/离线编程的局限，重点落到**曲线焊缝**：空间曲线焊缝逐点示教成本极高、装夹偏差导致轨迹漂移。
- 感知手段引出：**线激光（eye-in-hand）**——截面精度高、直接获取坡口几何信息（间隙、钝边、角度）、对金属反光相对不敏感，天然适合曲线焊缝。
- CAD 先验引出：以 CAD 模型为数字基准，引导扫描路径、约束焊缝识别，而非被动配准。
- 点出核心难点：**窄视场 + 曲线焊缝 + 必须主动扫描 + 夹具/坡口自遮挡** 的矛盾。

### 1.2 研究意义

- **理论意义**：CAD 先验引导的焊接任务解析与焊缝位姿感知；工艺—运动学耦合的 6-DOF 免示教轨迹优化；面向焊缝偏差的轨迹执行与自适应调整；免示教焊接机器人系统的集成方法与实验验证。
- **工程意义**：曲线焊缝免示教，亚毫米精度、缩短换型周期，降低焊偏与撞枪风险。

## 三、研究目标、研究内容与拟解决的关键问题

### 3.1 研究目标

以 CAD 模型为数字基准、eye-in-hand 线激光为感知手段，解析焊接任务并感知实测焊缝位姿与工件状态，据此规划六自由度免示教焊接轨迹并实现执行中的自适应调整，最终集成软硬件系统完成典型曲线焊缝工件的免示教焊接实验验证。

### 3.2 研究内容（四条：感知—规划—执行—集成）

**（1）基于 CAD 先验与线激光的焊接任务解析与焊缝位姿感知**
- 从 CAD 模型自动解析焊接任务：提取焊缝类型、坡口几何、期望轨迹初值（曲线焊缝具体化为相贯线 / 空间曲线角接）。
- CAD 面求交生成理论曲线先验，作为识别与测量的数字基准。
- **实际焊缝位姿与工件状态感知**：以 CAD 先验给出粗定位与 ROI 预测，线激光精测，形成"CAD 粗定位 + 线激光精测"两级机制。
- **自适应观测位姿规划**：针对窄视场 + 曲线焊缝 + 夹具/坡口自遮挡的矛盾，用 next-best-view 主动视点规划以最少视点补覆盖、消遮挡，并满足 eye-in-hand 安装下的观测位姿可达性约束。
- 识别与位姿估计联合进行（非串行解耦）：用 CAD 先验同时约束焊缝识别与位姿估计。

**（2）融合焊接工艺与运动学约束的六自由度免示教焊接轨迹规划**
- 输入承接第（1）条输出的实测焊缝位姿与工件状态，生成执行端焊接轨迹。
- 6-DOF 真正价值：绕焊枪轴线的**冗余自由度**。
- 焊接工艺姿态约束（行走角/工作角/倾角）× 运动学可达性（避奇异、避碰撞）**耦合求解**。
- 沿曲线焊缝的连续姿态规划，轨迹由 CAD + 实测自动生成、无需人工示教。

**（3）面向焊缝偏差的免示教焊接轨迹执行与自适应调整**
- 本课题不涉及底层关节实时伺服控制，该环节定位为**上层轨迹执行层的非实时闭环调整**。
- 焊接前：依据感知结果对规划轨迹做离线修正（装配偏差、坡口实测值回代）。
- 焊接中：线激光/视觉间歇采样 → 与 CAD 基准比对 → **分段式轨迹修正 + 工艺参数调整**（非连续实时伺服，而是按焊缝分段/采样周期自适应）。
- 与第（2）条的边界：第（2）条产出初始轨迹，本条负责执行中的偏差自适应调整。

**（4）免示教焊接机器人系统集成与实验验证**
- 系统总体架构设计：硬件平台（工业机器人 + eye-in-hand 线激光 + 焊接电源/送丝机构）+ 软件框架（任务解析 / 感知测量 / 轨迹规划 / 执行调整模块的分层解耦与接口定义）。
- 各功能模块集成与数据流协同：将前三条成果整合为"解析—感知—规划—执行"一体化的免示教焊接流程。
- 软硬件接口与通讯：机器人控制器开放接口、线激光相机数据采集、焊接电源协同控制的实时衔接。
- 面向典型曲线焊缝工件（相贯线 / 空间曲线角接）的整机免示教焊接实验验证，并以装配偏差等场景检验系统鲁棒性。

### 3.3 拟解决的关键问题（与研究内容一一对应）

1. 面向曲线焊缝的 CAD 焊接任务解析与焊缝位姿/工件状态感知。
2. 焊接工艺约束与运动学可达性耦合的 6-DOF 免示教轨迹规划。
3. 面向焊缝偏差的免示教轨迹执行与分段式自适应调整。
4. 免示教焊接机器人软硬件系统集成与实验验证。

## 四、研究方案与可行性分析

- 技术路线图（文字）：

```
CAD STEP 模型 → 焊接任务自动解析（焊缝类型/坡口几何/期望轨迹初值）→ 线激光相机标定(eye-in-hand)
→ CAD 先验 ROI 预测与初始位姿估计 → 实际工件状态感知 + 线激光主动扫描(观测位姿规划/遮挡规避)
→ 截面-轮廓联合识别与配准 → 实测焊缝位姿获取与质量判定
→ 实测焊缝与 CAD 基准融合 → 6-DOF 免示教轨迹规划(工艺约束×运动学)
→ 焊缝偏差自适应调整(分段式轨迹修正 + 工艺参数调整)
→ 系统集成（软硬件接口/多模块协同）→ 免示教焊接实验验证 → 轨迹插补与机器人执行
```

- 关键公式：线激光三角测量重建、截面-轮廓匹配误差、6-DOF 轨迹（含冗余自由度）、不确定性传播模型。
- 可行性：理论 / 技术 / 硬件（eye-in-hand 线激光 + 机械臂开放运动控制接口）/ 前期基础 / 风险。
