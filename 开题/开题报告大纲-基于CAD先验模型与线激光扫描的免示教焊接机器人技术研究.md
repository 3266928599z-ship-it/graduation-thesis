# 开题报告大纲（新题目对齐版）

**题目：基于 CAD 先验模型与线激光扫描的免示教焊接机器人技术研究**

> 说明：本文档为新题目下的开题报告大纲，用于对齐题目、技术路线、研究内容、关键问题与实验方案。目标场景为曲线焊缝，线激光相机安装于机械臂末端（eye-in-hand）。

---

## 一、选题背景与研究意义

### 1.1 选题背景

- 焊接自动化产业背景：钢结构、船舶、轨道交通、重型装备制造的基础工艺；焊工短缺、人工成本攀升。
- 工业机器人增长与自主适应能力不足的矛盾：机器人数量增长 ≠ 自主适应能力提升。
- 传统示教/离线编程的局限，重点落到**曲线焊缝**：空间曲线焊缝逐点示教成本极高、装夹偏差导致轨迹漂移。
- 感知手段引出：**线激光（eye-in-hand）**——截面精度高、直接获取坡口几何信息（间隙、钝边、角度）、对金属反光相对不敏感，天然适合曲线焊缝。
- CAD 先验引出：以 CAD 模型为数字基准，引导扫描路径、约束焊缝识别，而非被动配准。
- 点出核心难点：**窄视场 + 曲线焊缝 + 必须主动扫描 + 夹具/坡口自遮挡** 的矛盾。

### 1.2 研究意义

- **理论意义**：CAD 先验引导的曲线焊缝识别与位姿联合估计；窄视场传感器主动视点规划；6-DOF 冗余自由度下的轨迹优化；不确定性沿曲线焊缝的传播与闭环抑制。
- **工程意义**：曲线焊缝免示教，亚毫米精度、缩短换型周期，降低焊偏与撞枪风险。

## 三、研究目标、研究内容与拟解决的关键问题

### 3.1 研究目标

以 CAD 模型为数字基准、eye-in-hand 线激光为感知手段，实现曲线焊缝工件的免示教识别、位姿配准、六自由度轨迹生成与在线闭环修正。

### 3.2 研究内容（四条）

**（1）CAD 先验约束的曲线焊缝识别与工件位姿配准**
- 曲线焊缝的具体化定义（相贯线 / 空间曲线角接）。
- CAD 面求交生成理论曲线先验。
- **识别与配准联合估计**（而非串行解耦）：用 CAD 先验同时约束焊缝识别与位姿配准。

**（2）面向遮挡规避的线激光主动扫描与机器人视点规划**
- 窄视场 + 曲线焊缝 + 夹具/坡口自遮挡的矛盾。
- next-best-view 主动视点规划，用最少视点补覆盖、消遮挡。
- eye-in-hand 安装下的视点可达性约束。
- **核心主线，创新性最强。**

**（3）CAD—线激光融合的免示教六自由度焊接轨迹生成**
- 6-DOF 真正价值：绕焊枪轴线的**冗余自由度**。
- 焊接工艺姿态约束（行走角/工作角/倾角）× 运动学可达性（避奇异、避碰撞）**耦合求解**。
- 沿曲线焊缝的连续姿态规划。

**（4）不确定性感知的焊接轨迹在线预测与闭环修正**
- 不确定性来源：位姿配准残差 + 装配误差 + 机械抖动（**不含热变形**）。
- 不确定性沿曲线焊缝的**时空传播**（曲率变化导致远端误差放大）。
- 概率框架下的"**预测—修正**"闭环（强调预测性，而非事后纠偏）。

### 3.3 拟解决的关键问题（与研究内容一一对应）

1. 线激光截面与 CAD 先验模型的联合识别与位姿估计。
2. 窄视场下曲线焊缝的主动视点规划与遮挡规避。
3. 工艺姿态约束与运动学可达性耦合的 6-DOF 轨迹生成。
4. 不确定性沿曲线焊缝的传播建模与在线闭环抑制。

## 四、研究方案与可行性分析

- 技术路线图（文字）：

```
CAD STEP 模型 → 理论曲线焊缝提取/投影轮廓生成 → 线激光相机标定(eye-in-hand)
→ CAD 先验 ROI 预测与初始位姿估计 → 线激光主动扫描(视点规划/遮挡规避)
→ 截面-轮廓联合识别与配准 → 位姿估计与质量判定
→ 理论焊缝与实测焊缝融合 → 6-DOF 轨迹生成(工艺约束×运动学)
→ 不确定性在线预测与闭环修正 → 轨迹插补与机器人执行
```

- 关键公式：线激光三角测量重建、截面-轮廓匹配误差、6-DOF 轨迹（含冗余自由度）、不确定性传播模型。
- 可行性：理论 / 技术 / 硬件（eye-in-hand 线激光 + 机械臂开放运动控制接口）/ 前期基础 / 风险。
